# Sparrow installation for CU TRaIL Thermochronology Lab 

This test lab implementation of [Sparrow](https://sparrow-data.org) is based on data from
University of Colorado's [TRaIL](https://cutrail.org/) thermochronology
lab under Becky Flowers.

# Installation and usage

- Install `sparrow`
- Run `sparrow` from within this directory

## Installation for local development and testing

There are numerous tests of data reduction processes in this
repository.

- Install the [Poetry](https://getpoetry.com) package manager
- Run `poetry install`
- Run `make test` or `poetry run pytest`
